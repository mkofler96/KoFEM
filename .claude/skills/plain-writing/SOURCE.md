at commit `49919866efe619c6689946774234025894b948a3`.

The upstream skill and reference files were originally copied without modification.
This repository now adds a computational-engineering register section to SKILL.md
and `references/kofler-academic-style.md`, preserving the upstream MIT license.
The added reference is the maintainer's supplied "Academic Writing Style Guide
Based on Kofler et al. (2025)", retained in full. It describes general stylistic
features; the underlying paper was not supplied as part of this change.

The skill is installed only in this repository. The entry at
`.agents/skills/plain-writing` links to this directory for Codex discovery.
