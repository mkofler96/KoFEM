# Fluff, clichés, and redundancy

## Fluff words — delete on sight unless they carry real weight

really, very, totally, particularly, especially, definitely, actually, generally, basically,
for all intents and purposes, kind of, sort of, type of, individual, specific, in order to,
at this time, needless to say, it should be noted that

> We prefer BestPro as the particular brand for our PDUs. → We prefer BestPro PDUs.

## Throat-clearing openers

| Wordy opener | Fix |
| --- | --- |
| I'm writing this email because I want to ask you… | Ask the question. |
| It has come to our attention that… | State the fact. |
| At this time it is recommended that… | We recommend… |
| The purpose of X is to… | X does… |
| There are several reasons why we would recommend… | We recommend… because… |

## Words that state the obvious

> We implemented a successful solution. → We implemented a solution.

A solution that does not work is not a solution. Watch for *successful*, *final outcome*, *actual fact*, *advance planning*.

## Jargon

Jargon is fine when every reader knows the term and it is the shortest accurate route. Otherwise it either excludes readers or sounds condescending. If you must use it and are unsure, define it on first use or pick a more precise plain word.

## Clichés

Ambiguous, hard to translate, and unprofessional in writing.

| Cliché | Say instead |
| --- | --- |
| ballpark figure | about, around, approximate |
| run of the mill | standard, common |
| think outside the box | be original, be creative |
| take the bull by the horns | act, take responsibility |
| once and for all | permanently |
| low-hanging fruit | the easiest items |
| move the needle | change the result |
| circle back | follow up |

## Redundancies

| Redundant | Correct |
| --- | --- |
| various differences | differences |
| each individual | each *or* individual |
| reply back | reply |
| future plans | plans |
| end goal | goal |
| final outcome | outcome |
| free gift | gift |
| past experience | experience |
| unexpected surprise | surprise *or* unexpected |
| sudden crisis | crisis |
| advance warning | warning |
| close proximity | proximity *or* near |
| pick and choose | pick *or* choose |
| completely eliminate | eliminate |

## The fluff test

Circle every candidate word. Read the sentence aloud, skipping them. Reword only as much as grammar requires. If the meaning survives, the words were fluff — delete them.
