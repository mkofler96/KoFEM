Reference elements and Jacobians

On this page

  • Jacobian: local directions and scale
  • Transform a shape-function gradient

  • Check the mapping
  • Sources and further reading

How can the same shape functions and integration points work on different elements?

Define them once on a simple reference element, then map them to each physical element. The Jacobian converts directions, derivatives and integration weights. This page considers three-dimensional volume elements; surface and shell mappings need surface measures instead.

Map one reference element

Let ξ=​(ξ,η,ζ)T be dimensionless reference coordinates. The map x=​F(ξ) takes a reference point (3-vector) to a physical position (3-vector, mm). For an isoparametric element,

xi=Fi(ξ)=∑aNar(ξ)xai.

Here xa is physical node a’s position and Nar is its reference shape function. The upright superscript r labels a reference quantity; it is not a power. For a linear reference tetrahedron, ξ,η,ζ≥​0 and ξ+η+ζ≤​1; its shape functions are 1−ξ−η−ζ, ξ, η and ζ.

Use an affine map x=​10+2ξ+η, y=​20+3η, z=​30+4ζ, with physical lengths in mm. It maps the reference origin to (10,20,30) mm and the three other vertices to (12,20,30), (11,23,30) and (10,20,34) mm. At ξ=​η=​ζ=​1/4, the physical point is (10.75,20.75,31) mm.

Jacobian: local directions and scale

The Jacobian J is the 3 × 3 derivative of F. Its row is the physical component and its column the reference direction:

Jij=∂xi∂ξj,dxi=Jijdξj.
J=[210030004]

Each column is a mapped reference-axis direction, in mm. A small step h in η moves the physical point by (h,3h,0) mm. The determinant is 2×3×4=​24 mm3: it scales volume, while its sign records orientation. The translation (10,20,30) does not affect J.

Transform a shape-function gradient

The chain rule for a scalar q gives ∂qr/∂ξj=​(∂q/∂xi)Jij, where qr(ξ)=​q(F(ξ)). In particular, the physical shape function is Na(x)=​Nar(F−1(x)). With gradients stored as column 3-vectors, this means ∇ξqr=​JT∇xq, hence:

∇xNa=J−T∇ξNar.

J−T means (J−1)T. The output is a 3-vector with units 1/mm, since Na is dimensionless. For N2r=​η, its reference gradient is (0,1,0)T. The inverse transpose is:

J−T=[1/200−1/61/30001/4]

Thus ∇xN2=​(0,1/3,0)T mm−1. Independently, η=​(y−20)/3, giving the same derivative. Multiplying by J−1 instead would incorrectly give (−1/6,1/3,0)T. The skew in this example makes the transpose matter.

A nonzero gradient in x is visible for N1r=​ξ: ξ=​(x−10)/2−(y−20)/6, so ∇xN1=​(1/2,−1/6,0)T mm−1. These transformed gradients enter the displacement gradient and the B matrix.

Transform an integral

Changing variables converts a physical volume integral into a reference integral. For a scalar integrand g, both sides are scalars:

∫Ωeg(x)dV=∫Ωrg(F(ξ))|detJ(ξ)|dξdηdζ.

Ωe is the physical element and Ωr its reference tetrahedron. Integrating g=​1 checks the volume. The reference tetrahedron has volume 1/6; our constant determinant therefore gives 24/6=​4 mm3.

Numerical quadrature replaces the reference integral by a weighted sum, ∑qg(F(ξq))|detJ(ξq)|ωq, with dimensionless reference points ξq and weights ωq. For this constant integrand, a centroid point with weight 1/6 gives the exact volume. This does not make one-point quadrature exact for general element stiffness or load integrands.

Element stiffness uses transformed shape-function derivatives and the volume factor together, for example K(e)=​∫ΩeBTCBdV. Here B maps displacement coefficients to engineering strain, and C maps engineering strain to stress. B has units 1/mm and C has units N/mm², so a solid translational stiffness entry has units N/mm. Elements and quadrature evaluates this integral for one tetrahedron and explains the choice of rule.

Check the mapping

A zero determinant means the local volume has collapsed and J cannot be inverted. A small volume scale or highly stretched directions can amplify derivative errors. A negative determinant records a reversed orientation; the absolute value in the change-of-variables identity is not permission to accept an inverted FEM element. Valid orientation and connectivity must be checked using the element’s convention.

Affine elements have constant J. Curved or higher-order maps generally require J at each quadrature point, and a map that folds over itself is invalid even if a few sampled determinants are nonzero. Surface elements use tangent vectors and an area factor, not this 3D volume determinant. Integration order, element quality and solver conditioning remain separate questions.
