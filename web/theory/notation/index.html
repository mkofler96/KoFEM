What do the shared symbols, indices, coordinate conventions and units mean?

Use this page as a lookup reference while reading the guide. Each article defines its local notation at first use and links back to these definitions. A local definition takes precedence when a symbol has another meaning.

How to read the notation

Italic letters such as E denote scalars. Bold lowercase letters such as u denote vectors; bold uppercase Latin letters such as K denote matrices. Bold Greek letters such as σ denote second-order tensors. A tensor describes a physical quantity independently of coordinates; a matrix stores its components in a chosen basis. Components such as ui and σij are scalars.

A field assigns a value to every position: displacement u depends on x. A discrete coefficient vector d is instead a finite list of unknown numbers. Its length is the number of degrees of freedom, not the number of spatial dimensions.

Use a fixed Cartesian basis with x1=​x, x2=​y and x3=​z. Spatial indices i,j,k range from 1 to 3. Repeated spatial indices in one term are summed (Einstein convention): aibi=​a1b1+a2b2+a3b3. A free index labels the component of the result. Node or basis indices a,b and element indices e use explicit sums.

A subscript can also be a label: σvm means von Mises stress, not a sum over indices v and m. A superscript h marks an FEM approximation, (e) an element-local quantity, and T a transpose; other numerical superscripts are powers. The Kronecker delta δij is 1 for equal indices and 0 otherwise. The identity tensor I has these components. These are dimensionless. A plain δ may instead mean the bar’s extension when an article defines it that way.

Units below use N and mm to make dimensions concrete. The consistent unit systems reference covers other choices. “1” means dimensionless; vector and matrix sizes describe their shape, not their physical units.

Finite element quantities

For a three-dimensional solid displacement approximation with nb scalar basis functions, there are nd=​3nb translational coefficients before constraints. Interpolation reconstructs the displacement field from those coefficients. In component form:

uih(x1,x2,x3)=∑a=1nbNa(x1,x2,x3)dai.
Translational solid finite element quantities
SymbolMeaning and typeUnits
NaScalar shape function for basis a; dimensionless field. The interpolation matrix N groups NaI blocks and has size 3×nd, so uh=​Nd. Upright N in a unit is a newton, not a shape function. See coefficients. Linear and quadratic shape functions.1
dDiscrete displacement coefficient vector of length nd; dai is its coefficient for basis a, component i. In a nodal displacement basis these are nodal values; higher order adds nodes beyond the corners. See returned vertex samples.mm
BStrain–displacement matrix; size 6×nd in the engineering-shear convention below. Spatial derivatives of the shape functions give εeng=​Bd. B blocks and a worked element.1/mm
KGlobal stiffness matrix; size nd×nd. It maps translational coefficients to force in Kd=​f, with constraints treated appropriately. See the dimensional check. Assembly example.N/mm
fAssembled load vector of length nd; it includes concentrated loads and work-equivalent surface or volume contributions. A traction is integrated with shape functions, not copied into a force entry. See integration. Work-equivalent face loads.N

The interpolation matrix above groups coefficients by basis: (d1x,d1y,d1z,d2x,…). Storage order is a numbering choice; changing it consistently leaves the physical approximation unchanged. See DOF ordering.

These matrix sizes and units describe a translational solid problem. Shells add rotations (radians, dimensionless) and moments (N·mm), so their stiffness blocks have different units. A display-tessellation vertex is not automatically an FEM node, and a node identifier is not a DOF index.

Shell rotations and resultants

These symbols extend the solid notation for the flat-facet shell formulation. Shell fields use each facet’s local right-handed basis; a local thickness coordinate is distinct from global z.

For shell unknowns, stiffness translation–translation, translation–rotation and rotation–rotation blocks have units N/mm, N and N·mm respectively. See coupling virtual work.

Operator reference

The definitions below fix the convention used by this guide. Detailed operator examples are linked from each entry.

∇ — Gradient
Spatial derivative. For a scalar q, (∇q)i=​∂q/∂xi is a 3-vector. For a vector v, (∇v)ij=​∂vi/∂xj is a 3 × 3 tensor: row i is the component being differentiated. Units are those of the field divided by mm. Displacement’s gradient is dimensionless. See symmetric gradient. Scalar and vector gradient examples.
sym∇ — Symmetric gradient
The symmetric part of the vector gradient: εij=​(∂ui/∂xj+∂uj/∂xi)/2. It is a symmetric 3 × 3 tensor with units of displacement per length, hence dimensionless. See shear components. Small-strain calculation.
∇· — Divergence
For a vector v, ∇·v=​∂vi/∂xi is a scalar. For stress, (∇·σ)i=​∂σij/∂xj is a 3-vector. Each has the field’s units divided by mm. Thus ∇·σ and body force both have units N/mm³ in equilibrium, ∇·σ+b=​0. Vector and stress divergence examples.
AT — Transpose
Swap rows and columns: (AT)ij=​Aji. An m×n matrix becomes n×m; physical units stay the same. The symmetric part of A is (A+AT)/2. See small strain. Transpose example.
a·b — Dot product
The scalar aibi for two 3-vectors. Units multiply: force dotted with displacement has work units N·mm. The norm |a|=​a·a has the same units as a. See virtual work. Dot-product example.
a⊗b — Outer product
Two 3-vectors form a 3 × 3 tensor, (a⊗b)ij=​aibj; units multiply. Unlike a dot product, it retains two directions. See the outer-product calculation and its role in displacement interpolation.
A:B — Double contraction
The scalar AijBij, summed over both spatial indices for two second-order tensors. Units multiply. For symmetric tensors both off-diagonal entries contribute: σ:ε includes 2σxyεxy, and similarly for the other shear pairs. See engineering shear. Contraction and shear calculation.
tr(A) — Trace
The scalar Aii=​A11+A22+A33 of a 3 × 3 tensor; units stay the same. For strain, it measures the first-order relative volume change. See the isotropic material law. Trace example.
ξ — Reference coordinates
A dimensionless 3-vector locating a point in a reference volume element. The map x=​F(ξ) gives the physical position in mm. See the tetrahedron example.
J — Mapping Jacobian
The 3 × 3 matrix Jij=​∂xi/∂ξj, in mm. Its determinant scales volume; its inverse transpose transforms column gradients. See the Jacobian calculation and gradient transformation.
∫Ω(·)dV,∫Γ(·)dS — Integrals
Sum a field over a volume or surface. Units multiply by mm³ or mm². For example, the solid nodal force contribution ∫ΓNatidS has units N. Virtual work ∫Ωε(w):σdV, ∫Ωw·bdV and ∫Γw·tdS each has units N·mm. See test displacement and assembled loads. Integration and virtual-work examples.

Components, shear and signs

Global vectors use x,y,z order in a right-handed Cartesian frame; positive displacement and force components point along the corresponding positive axis. Positive normal stress means tension. For a solid, positive pressure acts inward, opposite the outward normal. A shell facet instead takes its normal from node winding; it has no unique outward side. KoFEM’s positive shell pressure acts against that winding normal.

Tensor strain and engineering shear

Tensor shear εxy is half the engineering shear γxy. This guide orders six-component solid arrays as xx,yy,zz,yz,xz,xy and writes:

εeng=(εxx,εyy,εzz,2εyz,2εxz,2εxy)T.
σvec=(σxx,σyy,σzz,σyz,σxz,σxy)T.

Shear stresses are not doubled. With this pairing, σ:ε=​σvecTεeng. Other texts and libraries use different orders; check both order and shear scaling before multiplying arrays.

For a simple shear displacement ux=​αy,uy=​uz=​0, choose α=​0.002. Then εxy=​0.001 and γxy=​0.002. With μ=​80000 MPa, σxy=​2μεxy=​μγxy=​160 MPa. Using tensor shear in an engineering-shear matrix would halve this stress.

KoFEM’s solid recovery computes the full 3 × 3 tensor directly. Its topology stress operator uses the six-component order above with engineering shear. Shell membrane calculations use local (εxx,εyy,γxy) and (σxx,σyy,τxy); τxy is the same shear stress component as σxy. Local shell axes follow the facet, not global x,y,z.

Von Mises stress uses the deviatoric tensor sij=​σij−tr(σ)δij/3:

σvm=32sijsij.

The solid output samples it at each element centre. Shell output takes the greater value at the two surfaces, including membrane and bending. Coupled output keeps separate solid and shell element values. Smoothed viewport colours are derived values, not additional solved unknowns.

KoFEM units and a dimensional check

At the reviewed revision, the app labels and defaults use mm for length, displacement and shell thickness; N for force; N·mm for moment; and MPa (N/mm²) for Young’s modulus, pressure and stress. Mass density is labelled tonne/mm³. Default steel has E=​210000 MPa, ν=​0.3 and ρ=​7.85×10−9 tonne/mm3.

The static solid, shell and coupled payloads pass numerical coordinates, stiffnesses, section sizes and loads without automatic unit conversion. The engine does not attach units to those numbers. The current static payloads do not use stored mass density to generate gravity or inertia. Check imported geometry scale and enter compatible values; the fixed result labels do not prove that inputs were consistent.

For a general comparison of SI m–kg–s, N–mm–s, N–mm–ms, kN–mm–ms, CGS and US customary systems, see the separate unit-system table and material conversions. SI uses Pa for stress and modulus; N–mm uses MPa. Converting changes the numbers for both material input and stress output while preserving the physical quantities. This does not imply a unit-system selector in KoFEM.

Follow force through stiffness to displacement

Use the uniform axial bar with P=​1000 N, length L=​1000 mm, area A=​100 mm2 and E=​210000 MPa. Here A is area, not a stiffness matrix. Its axial stiffness is a scalar:

kbar=EAL=210000 N/mm2×100 mm21000 mm=21000 N/mm.

Stress is P/A=​10 MPa. Strain is σ/E≈​4.7619×10−5, dimensionless. Extension is δ=​P/kbar=​εL≈​0.047619 mm. Thus stiffness (N/mm) times displacement (mm) gives force (N), as required by Kd=​f. The bar permits lateral contraction and assumes uniform axial stress; a three-dimensional clamp changes the local stress state.

In SI the same inputs are L=​1 m, A=​10−4 m2 and E=​2.10×1011 Pa. They give kbar=​2.10×107 N/m, σ=​107 Pa and δ≈​4.7619×10−5 m. The extension and stress are physically identical to the N–mm calculation.

Reading the implementation

Textbook symbols describe mathematical roles; local variable names need their surrounding code. In particular:

  • vertices stores xyz-interleaved positions. MFEM’s x GridFunction stores displacement coefficients, not spatial coordinates. The guide calls those coefficients d.
  • A_mat, X and B in the solid linear solve play the roles of stiffness, unknowns and right-hand side. That B is not the guide’s strain–displacement matrix.
  • young/young_modulus and poisson/poisson_ratio mean E and ν. lam and mu are the Lamé parameters.
  • eps is tensor strain in solid recovery; its local s array is full stress, although s in the equation above denotes deviatoric stress. Shell code also uses local w for normal displacement; the guide reserves w for a test field.
  • displacements returns [ux,uy,uz] per vertex/node; the UI calls these Ux, Uy, Uz. Solid order-2 coefficient vectors also contain higher-order DOFs; returned corner samples do not contain the full vector. Shell/coupled internals group [ux,uy,uz,θx,θy,θz] at each node; the displacement result returns translations. MFEM element coefficient arrays use component-major order (all x, then all y, then all z), rather than the basis grouping used in the interpolation above.
  • von_mises is a scalar per element, not a six-component stress array. The standard solid solve does not return a Voigt stress vector. totalForce can hold N, N·mm or MPa according to the load group’s kind; the name alone does not establish its units.
