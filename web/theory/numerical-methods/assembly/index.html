How do element contributions become the global linear system?

Each element knows only its own nodes. Assembly adds every element’s stiffness and load into one global system. Where elements share a node, their contributions add. Units are N, mm and MPa.

Local and global degrees of freedom

A degree of freedom (DOF) is one unknown coefficient: one displacement component of one basis function. An element numbers its DOFs locally, 0 to 3ne−1. The model numbers every DOF once, globally. The element’s connectivity, its list of global node numbers, links the two numberings.

For a solid with nb scalar basis functions, the global coefficient vector d has nd=​3nb entries. At order 1, nb is the number of mesh vertices. Order 2 adds one function per tetrahedral edge; on hexahedra it also adds one per face and one per element. For example, a 10 × 2 × 2 grid of hexahedra has 11×3×3=​99 vertices and 297 DOFs at order 1. At order 2 its nodes form a 21 × 5 × 5 lattice: 525 functions and 1575 DOFs.

Worked example: two bar elements

Use the axial bar from Model and units: length L=​1000 mm, area A=​10000 mm2, E=​210000 MPa and end force P=​106 N. Split it into two 500 mm elements with nodes 1, 2 and 3. Each node has one DOF, its axial displacement in mm. Each element is a spring of stiffness:

k=EALe=210000×10000500 N/mm=4.2×106 N/mm.
K(e)=k[1−1−11]

Element 1 connects nodes (1, 2); element 2 connects (2, 3). Add each 2 × 2 block into the rows and columns of its nodes. Node 2 belongs to both elements, so its diagonal receives k twice:

K=k[1−10−11+1−10−11]

The load vector is f=​(R,0,P) N, where R is the unknown support reaction at node 1. As assembled, K is singular: each row sums to zero because a rigid translation costs no energy. Fixing node 1 (d1=​0) leaves two equations for the two unknowns:

k(2d2−d3)=0,k(−d2+d3)=P.

Solving gives d2=​P/k=​5/21 mm≈​0.238 mm and d3=​2P/k=​10/21 mm≈​0.476 mm. This equals the analytical PL/(EA). The first row then gives R=​−kd2=​−106 N, balancing P. Linear elements are exact here because the true displacement of a uniform bar without body load is linear. Supports are treated in detail in Loads and constraints.

Assembly as gather and scatter

Formally, a Boolean matrix Ae of size 3ne×nd gathers the element’s DOFs from the global vector: d(e)=​Aed. Equating the internal work of the elements with the global work gives:

K=∑eAeTK(e)Ae,f=∑eAeTf(e).

Ae is never built. Implementations keep a list of the element’s global DOF indices and add entry (i,j) of K(e) to entry (gi,gj) of K, where gi is the global index of local DOF i. Elements may be processed in any order. In the bar, element 1 has indices (1, 2) and element 2 has (2, 3).

Two tetrahedra sharing a face

Take five vertices, 0 to 4, and two order-1 tetrahedra: T1=​(0,1,2,3) and T2=​(1,2,3,4). They share the face (1,2,3). With nb=​5, there are 15 global DOFs. Using the component-blocked order explained below, component c=​0,1,2 (x,y,z) of vertex v has global index v+5c:

Global DOF indices per element
Elementx DOFsy DOFsz DOFs
T1 (0, 1, 2, 3)0, 1, 2, 35, 6, 7, 810, 11, 12, 13
T2 (1, 2, 3, 4)1, 2, 3, 46, 7, 8, 911, 12, 13, 14

Each 12 × 12 element matrix lands in a 15 × 15 global matrix. Nine DOFs belong to both elements, so the 9 × 9 block of the shared face receives two contributions. Vertices 0 and 4 share no element, so their 3 × 3 coupling block stays zero. Of the 25 vertex pairs, 23 are coupled: the global matrix has 23×9=​207 structural nonzeros out of 225. In a large mesh each vertex couples only to its neighbours, so almost all entries are zero and K is stored as a sparse matrix.

DOF ordering

Two orders are common for the same coefficients:

  • Interleaved (by node): (d0x,d0y,d0z,d1x,…), index 3v+c. The notation reference and the B blocks on the elements page use this order.
  • Component-blocked: all x coefficients, then all y, then all z, index v+nbc.

KoFEM’s solid solve uses MFEM’s default, component-blocked global order. MFEM’s elasticity integrator also orders each element matrix by component: local index k+nec. The two orders differ only by a permutation matrix P: Kblocked=​PKinterleavedPT. For the worked tetrahedron, exact arithmetic confirms that MFEM’s form equals the permuted BTCB matrix. The displacement field and every physical result are unchanged; only array positions differ.

At order 1 the scalar index of a vertex DOF is the input vertex index, so the x,y,z displacement of vertex v sits at v, v+nb and v+2nb. At order 2, edge functions follow all vertex functions. When MFEM corrects a tetrahedron’s orientation it reorders that element’s local corners; global vertex numbers do not change.

Properties of the global matrix

  • Size: nd×nd, N/mm. The load vector has nd entries in N.
  • Symmetric, because every element matrix is.
  • Sparse: nonzero only where two DOFs share an element.
  • Positive semi-definite before supports: the strain energy 12dTKd is never negative.
  • Singular before supports: every unconnected body has six rigid-body modes. Supports must remove all of them before the system can be solved.

Bodies with different materials still assemble into one K. Each element uses its own body’s λ and μ, and contributions add at shared nodes. The Linear solve page explains how the constrained system is solved.

KoFEM and MFEM responsibilities

Reviewed on 2 November 2026 at 41aa05f, against MFEM 4.7. The solid solve is solve_linear_elastic.

Textbook step to production code
StepOwnerWhat happens
Mesh and connectivityKoFEM, MFEMKoFEM adds vertices and tetrahedra/hexahedra with a material attribute per element (fem_mesh_io.cpp); MFEM builds edges and faces and fixes element orientation.
Shape functions and DOF numberingMFEMAn order-k H1 space with three components, component-blocked (solve_mfem.cpp).
Material per elementKoFEMλ and μ from each body’s E and ν, selected by element attribute (solve_mfem.cpp).
Element stiffness and quadratureMFEMElasticity integrator with its default rule (bilininteg.cpp).
Scatter-add into KMFEMBilinear-form assembly into a sparse matrix (solve_mfem.cpp).
Surface loadsKoFEM, MFEMKoFEM builds the traction for each force, traction or pressure group and marks its faces; MFEM integrates Nat (fem_bc_io.cpp).
Point loadsKoFEMAdded directly to the assembled load vector at a vertex’s three DOFs (fem_bc_io.cpp).
SupportsKoFEM, MFEMKoFEM lists constrained DOFs, extending them to order-2 edge DOFs (fem_bc_io.cpp); MFEM eliminates them (solve_mfem.cpp).
Mixed solid–shellKoFEM, MFEMThe same order-1 MFEM solid matrix, renumbered into KoFEM’s coupled DOF list (solve_coupled.cpp).

KoFEM-specific decisions are the element order offered, the material mapping, the conversion of face forces to tractions and the treatment of supports. Shape functions, quadrature and the scatter-add are MFEM’s. The axial bar example runs this complete path in the browser engine; reproduce it with node examples/validation/run.mjs --case axial-bar.
