Reproduce

From a clone (Node.js 20+, bash, curl):

git clone https://github.com/mkofler96/KoFEM.git && cd KoFEM
bash scripts/fetch-wasm-engine.sh
node examples/validation/run.mjs

prints every case, for example:

Case                               Quantity                                  FE   Reference     Err%  Tol%  Status
Surface traction (axial bar)       tip extension δ                    4.7358e-4   4.7619e-4    -0.55     2  PASS

In the app: Open the axial bar ↗ then run Studies → Static 1 → Run static solve, select the result plot and set Field to Ux. The Result summary shows Max Ux 4.736e-1 mm; the end-face mean, 0.47358 mm, is the Surface traction (axial bar) result in mm.
