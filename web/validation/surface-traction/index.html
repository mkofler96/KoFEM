Analytical solution

The analytical answer is the axial bar's (derivation):

δ=PLEA=4.7619×10−4 m.

What this case adds is the load vector. In the finite element method a traction t on a surface Γ enters through the work it does, so the force on node i is

fi=∫ΓNitdS,

where Ni is the shape function of that node. On linear quadrilateral faces of size h×h under a uniform traction, a node collects th2/4 from each face it touches. An interior node of the end face gets th2, an edge node th2/2 and a corner node th2/4. The forces add up to tA=P, and they do the same work as the distributed traction on every displacement the elements can represent. Splitting P equally over the nodes, as the axial bar case does, gets the total right but not the distribution.

Finite element model

Mesh20 × 4 × 4 grid: 320 linear 8-node hexahedra (P1)
Unknowns525 nodes, 1,575 degrees of freedom
MaterialLinear elastic, isotropic
SolverKoFEM engine (MFEM), the same WebAssembly build the app runs: engine-bb451aa7afb6

KoFEM integrates the traction with MFEM's boundary integrator over the 16 quadrilateral element faces of the end face. The app does the same when a force is applied to a face, which is why this case and the in-app reproduction agree.

Discussion

The extension differs from PL/(EA) by −0.55 %. With a consistent load, what remains is the clamp. The x = 0 face is fully fixed, so near it the bar cannot contract sideways. That material is in a multiaxial state and stiffer than the 1-D model assumes, so the end moves slightly less. It is a difference between the 3-D body and the 1-D theory, not discretisation error, so it does not go away with a finer mesh.

The axial bar case, with the equal nodal split, comes out +0.23 %: there the uneven load distribution pushes the result the other way. The surface pressure case reuses this load path with a pressure.

Reproduce

From a clone (Node.js 20+, bash, curl), this solves the case with the same engine and prints its line:

git clone https://github.com/mkofler96/KoFEM.git && cd KoFEM
bash scripts/fetch-wasm-engine.sh
node examples/validation/run.mjs --case surface-traction
Case                               Quantity                                  FE   Reference     Err%  Tol%  Status
Surface traction (axial bar)       tip extension δ                    4.7358e-4   4.7619e-4    -0.55     2  PASS

In the app: Open the axial bar ↗ then run Studies → Static 1 → Run static solve, select the result plot and set Field to Ux. The Result summary shows Max Ux 4.736e-1 mm; the end-face mean, 0.47358 mm, is the Surface traction (axial bar) result in mm.
