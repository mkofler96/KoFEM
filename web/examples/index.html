Examples and validation

Models you can open in KoFEM with their supports and loads already set up. Each page shows the problem, the model and KoFEM's result.

Validation

Problems with a known answer, from theory or the literature. Each page derives the answer and compares KoFEM's result with it.

8 of 8 benchmarks within their tolerance · engine engine-5ceb743373dd · 2026-11-01 · results.json · source

  • Axial bar in tension

    Uniform tension. Checks material, supports and how a face load reaches the nodes.

    Tip extension δ: 0.47358 mm, −0.55 % from the reference

  • Bar under end pressure

    The bar pushed by a pressure. Checks the sign and the per-area scaling of pressure loads.

    Tip displacement u: −4.7358 × 10−3 mm, −0.55 % from the reference

  • Cantilever beam, linear hexahedra

    Bending with linear elements, which are too stiff in bending (shear locking).

    Tip deflection δ: −1.8378 mm, −3.51 % from the reference

  • Cantilever beam, quadratic hexahedra

    The same beam on a coarse mesh of quadratic elements, which do not lock.

    Tip deflection δ: −1.9398 mm, +1.84 % from the reference

  • Cantilever beam from a STEP file

    The cantilever built as you would build it: a STEP block, a Netgen mesh, a support and a load on CAD faces.

    Tip deflection δ: −1.9040 mm, −0.04 % from the reference

  • Square beam under torsion

    Torsion of a square section, which warps. The clamp holds the warping back.

    Angle of twist θ: 8.5783 × 10−4 rad, −2.42 % from the reference

  • Hollow shaft under torsion

    Torsion of a tube. Straight-sided elements make the circle a polygon.

    Angle of twist θ: 1.4683 × 10−3 rad, +1.34 % from the reference

  • Plate with a hole

    Kirsch's stress concentration at a hole. The one stress-based case, hence the wider band.

    Stress-concentration factor Kt: 2.7750, −7.50 % from the reference

  • Plate with a hole, shell elements

    The same plate as a single layer of shell triangles on its mid-surface instead of solid elements.

    Stress-concentration factor Kt: 2.9387, −2.04 % from the reference

  • Cook's membrane

    Tapered, skewed cantilever in shear. A standard distortion benchmark, dimensionless.

    Top-corner deflection: 24.042, +0.59 % from the reference

Reproduce

The benchmarks run in CI on every change. To run them yourself (Node.js 20+, bash, curl):

git clone https://github.com/mkofler96/KoFEM.git && cd KoFEM
bash scripts/fetch-wasm-engine.sh
node examples/validation/run.mjs

It prints one line per benchmark, for example:

Case                                  Quantity                                  FE   Reference     Err%  Tol%  Status
Axial bar in tension                  tip extension δ                      0.47358     0.47619    -0.55     2  PASS
