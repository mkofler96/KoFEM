Cantilever beam, linear hexahedra

A beam clamped at one end and loaded at the other is the standard bending benchmark. Bending is where simple solid elements struggle, so this case tests the element as much as the solver.

Analytical solution

Euler–Bernoulli beam theory assumes that cross-sections stay plane and perpendicular to the deformed axis, which neglects shear deformation. Take w(x) as the deflection, positive upwards, with the load P acting downwards at the tip. Equilibrium of the part beyond a section x gives the bending moment

M(x)=−P(L−x),

and the curvature is proportional to it:

EId2wdx2=M(x),I=bh312.

Integrating twice with the clamp conditions w(0)=0 and dwdx(0)=0 gives the deflection curve

w(x)=−Px26EI(3L−x),

and at the tip

δ=w(L)=−PL33EI.

For this beam I=8.3333×106 mm4 and δ=−1.9048 mm.

Timoshenko beam theory adds the shear deformation that Euler–Bernoulli leaves out. For a cantilever with a tip load it adds a second term,

δs=−PLκGA,κ=56,G=E2(1+ν),

which is 0.78 % of the bending term for this beam (span ten times the depth). A converged 3-D solid model should therefore deflect slightly more than PL3/(3EI).

MaterialLinear elastic, isotropic
SolverKoFEM engine (MFEM), the WebAssembly build the app runs: engine-5ceb743373dd

The beam is meshed with linear 8-node hexahedra. Each element is a cube with sides one quarter of the beam depth. The tip load is a force on the end face, which the app integrates as a uniform traction.

Discussion

KoFEM's deflection differs from the reference by −3.51 %: the linear elements are too stiff. The reason is shear locking. The edges of a linear hexahedron stay straight, so it cannot take the curved shape of a bent piece of beam; to bend at all, it has to shear. In a beam under pure bending the true shear strain is zero, so this spurious, parasitic shear stores strain energy that the real beam does not have, and the element is too stiff. The longer the element compared with the depth it spans, the worse it gets.

Refining the mesh cures it slowly. In the convergence study above the linear-element error goes −35.22 % → −12.42 % → −3.51 % → −0.88 % as the element size halves, approaching a factor of four per step: the second-order convergence of displacements with linear elements, once locking is under control.

Quadratic elements can bend, so they do not lock; see the quadratic hexahedra and the beam meshed from a STEP file. Their series settles near +1.48 %, above the reference. About +0.78 % of that is the shear deformation that Euler–Bernoulli theory leaves out. The rest comes from the 3-D stress state at the clamped root and the loaded end.

Reproduce

In the app: open the model, then Studies → Static 1 → Run static solve, select the result plot and set Field to Uy. The Result summary shows Min Uy -1.838e+0 mm.

From a clone (Node.js 20+, bash, curl), this solves the model with the same engine and prints its line:

git clone https://github.com/mkofler96/KoFEM.git && cd KoFEM
bash scripts/fetch-wasm-engine.sh
node examples/validation/run.mjs --case cantilever
