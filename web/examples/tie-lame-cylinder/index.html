Tied thick-walled cylinder

A flat interface is the easy case for a tie. On a curved one the two faceted surfaces of a tetrahedral mesh do not even run parallel, so every node of one side projects onto the other at a slightly different place. This cylinder is built from two rings, meshed on their own and tied across a gap, and must still deflect as Lamé's theory says.

Analytical solution

In a long cylinder (plane strain) the radial displacement of a ring r1≤r≤r2 under the pressures pi inside and po outside is Lamé's

u(r)=1+νE((1−2ν)C1r+C2r),C1=pir12−por22r22−r12,C2=(pi−po)r12r22r22−r12.

The inner ring a≤r≤c carries the bore pressure p and a contact pressure q at r=c. The tie makes the outer ring's bore follow it, uo(c+g)=ui(c), and passes the radial force on, so the outer ring carries qc/(c+g) at its bore. Both displacements are linear in q, and the condition gives q=25.257 MPa. The bore displacement then follows from the inner ring. Without the gap this is Lamé's single cylinder, u(a)=0.045397 mm; the gap, which the tie bridges rigidly, makes it slightly larger.

Finite element model

MeshNetgen, 4 mm maximum element size: 2,862 linear 4-node tetrahedra (P1)
Unknowns1,088 nodes, 3,264 degrees of freedom
MaterialLinear elastic, isotropic
SolverThe app's default solver (conjugate gradients with algebraic multigrid, KoFEM's Rust module, build fem-45b08a9e444e); geometry and mesh by the KoFEM engine (OCCT, Netgen), the WebAssembly build the app runs: engine-3397ae8ea1eb

A quarter of the cylinder is modelled, with symmetry supports on the two cut faces of each ring and both end faces held along the axis, which makes the state plane strain. The two rings are separate solids in one STEP file. Netgen meshes each on its own with linear tetrahedra and a 4 mm maximum element size, so the nodes of the two facing cylinders do not match.

The tie uses the dual mortar method: each node of one surface follows the other in an integral sense, over the exact overlap of the faces, which transfers the contact pressure without the noise of a node-to-surface tie. The bore displacement is read where the bore meets the y=0 and z=0 faces, where it is purely radial.

Discussion

KoFEM's bore displacement differs from the tied Lamé solution by −0.65 %. Most of that is the linear tetrahedra: the polygonal bore and outer surfaces, and the constant strain per element across the steep radial gradient near the bore, make the model a little stiff. The tie itself adds no visible error: the contact pressure crosses the curved, non-matching interface as through a single body.

Reproduce

In the app: open the model, then Studies → Static 1 → Run static solve, select the result plot and set Field to Displacement (magnitude). The Result summary shows Max |U| 4.589e-2 mm.

Or build it yourself, as this page's number was built:

  1. Import tie-lame-cylinder.step.
  2. Mesh with a 4 mm maximum element size, linear elements.
  3. Material Steel: E = 210000 MPa, ν = 0.3.
  4. Support “Symmetry x”: Ux = 0 on the faces through (0, 62.5, 5), (0, 88, 5).
  5. Support “Symmetry y”: Uy = 0 on the faces through (62.5, 0, 5), (88, 0, 5).
  6. Support “Plane strain”: Uz = 0 on the faces through (44.1942, 44.1942, 0), (44.1942, 44.1942, 10), (62.2254, 62.2254, 0), (62.2254, 62.2254, 10).
  7. Load “Pressure”: pressure 100 MPa on the face through (35.3553, 35.3553, 5).
  8. Run the static study. The Results panel compares bore radial displacement with u(a), Lamé rings tied at r = c.

From a clone (Bun, bash, curl and Rust), this builds and solves the model with the same engine and prints its line:

git clone https://github.com/mkofler96/KoFEM.git && cd KoFEM
bash scripts/fetch-wasm-engine.sh
cd web && bun install && bun run validate --case tie-lame-cylinder
