Cook's membrane

Cook's membrane (1974) is a tapered panel, clamped on one edge and sheared on the other. It has no closed-form solution. The finite element literature uses it because it combines bending and shear on a mesh that cannot be rectangular, which exposes elements that lock or lose accuracy when distorted.

Analytical solution

The panel is the quadrilateral with corners (0, 0), (48, 44), (48, 60) and (0, 44), of unit thickness, with E=1 and ν=1/3, in plane stress. A total shear force F=1 is spread uniformly over the right edge, and the left edge is clamped. The benchmark is dimensionless; in KoFEM's units it is E=1 MPa, F=1 N and lengths in mm, so the deflection reads in mm.

Without an analytical solution, the reference is the converged value of very fine plane-stress meshes reported in the literature, 23.96 (older sources round it to 23.91). It is the vertical deflection at M, the middle of the loaded edge. Many descriptions put the point at the top corner C instead, but the tables of standard elements compared with 23.96 (bilinear quadrilaterals: 18.29, 22.08 and 23.43 on 4 × 4, 8 × 8 and 16 × 16 meshes) are deflections at M; the corner moves more.

The panel behaves like a short, tapered cantilever: span 48, depth tapering from 44 to 16. Linear elements lock in its bending, as in the cantilever, and every element is skewed, so elements whose accuracy depends on rectangular shapes do poorly. Coarse meshes of simple elements land far below 23.96.

MaterialLinear elastic, isotropic
SolverThe app's default solver (conjugate gradients with algebraic multigrid, KoFEM's Rust module, build fem-acb6b9a64d43); geometry and mesh by the KoFEM engine (OCCT, Netgen), the WebAssembly build the app runs: engine-7303b4976800

KoFEM is a 3-D solver, so the panel is a slab of thickness t=1, meshed by Netgen with quadratic tetrahedra and clamped over the whole x=0 face. The x=48 face is split at y=52, so M is a corner of the geometry and therefore a node of every mesh. The load F is one force on both halves of that face, integrated as a uniform traction. The result is the vertical displacement of the node at M on the z=0 face; the slab is symmetric about its mid-plane, so the z=t face gives the same value.

A thin slab with free faces is close to plane stress, but not exactly: the clamp also holds the through-thickness contraction at x=0, which stiffens the slab a little.

Discussion

KoFEM gives 23.936 mm at M, −0.10 % from 23.96. In the convergence study quadratic tetrahedra level off at 23.942 mm (1 mm, −0.08 %). That small remaining difference is the 3-D slab, which is slightly stiffer than the plane-stress panel the reference solves; the mesh no longer changes it. Linear tetrahedra lock in the bending and approach from below: 23.833 mm at 1 mm (−0.53 %), no closer than quadratic ones at 16 mm (−0.50 %) with 5 times fewer unknowns. That is why the example uses quadratic elements.

The largest vertical displacement, at the top corner C, is 25.130 mm (Max Uy in the Result summary), +4.88 % from 23.96. An earlier version of this page compared C with the reference, so refinement moved past it.

Reproduce

In the app: open the model, then Studies → Static 1 → Run static solve, select the result plot and set Field to Uy. The Result summary shows Max Uy 2.513e+1 mm.

Or build it yourself, as this page's number was built:

  1. Import cooks-membrane.step.
  2. Split the face through (48, 50, 0.5) with the plane y = 52 mm.
  3. Mesh with a 2 mm maximum element size, quadratic elements.
  4. Material Membrane: E = 1 MPa, ν = 0.333333.
  5. Support “Clamp”: Ux, Uy, Uz = 0 on the face through (0, 22, 0.5).
  6. Load “Shear”: force (0, 1, 0) N on the faces through (48, 48, 0.5), (48, 56, 0.5).
  7. Run the static study. The Results panel compares deflection at m with converged plane-stress value.

From a clone (Bun, bash, curl and Rust), this builds and solves the model with the same engine and prints its line:

git clone https://github.com/mkofler96/KoFEM.git && cd KoFEM
bash scripts/fetch-wasm-engine.sh
cd web && bun install && bun run validate --case cooks-membrane
