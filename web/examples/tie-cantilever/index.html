Tied cantilever, quadratic hexahedra

The quadratic cantilever, cut at mid-span into two bodies that are meshed separately, with 2 × 2 elements across on the clamped half and 3 × 3 on the loaded half. A tie joins them. Unlike the patch test, bending is not a linear field: the tie has to carry a shear force and a bending moment between faces whose nodes do not match.

Analytical solution

Euler–Bernoulli beam theory assumes that cross-sections stay plane and perpendicular to the deformed axis, which neglects shear deformation. Take w(x) as the deflection, positive upwards, with the load P acting downwards at the tip. Equilibrium of the part beyond a section x gives the bending moment

M(x)=−P(L−x),

and the curvature is proportional to it:

EId2wdx2=M(x),I=bh312.

Integrating twice with the clamp conditions w(0)=0 and dwdx(0)=0 gives the deflection curve

w(x)=−Px26EI(3L−x),

and at the tip

δ=w(L)=−PL33EI.

For this beam I=8.3333×106 mm4 and δ=−1.9048 mm.

Timoshenko beam theory adds the shear deformation that Euler–Bernoulli leaves out. For a cantilever with a tip load it adds a second term,

δs=−PLκGA,κ=56,G=E2(1+ν),

which is 0.78 % of the bending term for this beam (span ten times the depth). A converged 3-D solid model should therefore deflect slightly more than PL3/(3EI).

Finite element model

Mesh5 × 2 × 2 and 5 × 3 × 3 grids, tied: 65 quadratic 27-node hexahedra (P2)
Unknowns814 nodes, 2,442 degrees of freedom
MaterialLinear elastic, isotropic
SolverKoFEM engine (MFEM), the WebAssembly build the app runs: engine-cb36c1e084cb

Each node of the finer face is tied to the face it projects onto, and follows that face's quadratic displacement field there. The nodes in the middle of the edges of a tied face follow its corners. This is the node-to-surface tie: KoFEM's mortar tie is implemented for linear elements, and quadratic faces fall back to projection. Projection fails the patch test on non-matching meshes (see the tie patch test), so this case measures how much that matters in bending.

Discussion

The tied beam deflects +1.86 % from the Euler–Bernoulli value; the uncut beam on a similar mesh deflects +1.84 %. The uncut beam's difference is the model, not the tie: shear deformation, which Euler–Bernoulli theory leaves out, and the 3-D stress state at the clamp and the loaded end. Cutting the beam and tying it adds 0.02 % of the reference deflection.

A deflection averages over the whole beam. Expect the stress right at a quadratic tie to be less accurate than this, until the mortar tie covers quadratic elements too.

Reproduce

In the app: open the model, then Studies → Static 1 → Run static solve, select the result plot and set Field to Uy. The Result summary shows Min Uy -1.940e+0 mm.

From a clone (Bun, bash, curl), this solves the model with the same engine and prints its line:

git clone https://github.com/mkofler96/KoFEM.git && cd KoFEM
bash scripts/fetch-wasm-engine.sh
cd web && bun install && bun ../examples/validation/run.mjs --case tie-cantilever
