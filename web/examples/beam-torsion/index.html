Square beam under torsion

Twisting a bar with a square section is the simplest torsion problem that the circular-shaft formula gets wrong. The sections do not stay plane: they warp out of their plane, and the bar is softer in torsion than its polar moment of inertia suggests. The case checks that KoFEM captures this 3-D behaviour.

Analytical solution

In a circular shaft the shear stress grows linearly with the radius and the torsional stiffness is GJ, with the polar moment J. Saint-Venant's theory (1855) covers any section. Each section rotates rigidly in its own plane by an angle that grows linearly along the bar, θ(x)=θ′x, and is free to warp axially by ux=θ′ω(y,z), with a warping function ω that depends on the shape of the section.

The shear stresses follow from Prandtl's stress function φ(y,z), with τxy=∂φ/∂z and τxz=−∂φ/∂y. Compatibility requires

∇2φ=−2Gθ′ in the section,φ=0 on its boundary,

and the torque is twice the volume under φ:

T=2∫AφdA=GKθ′.

This defines the torsion constant K. For a square of side b the series solution gives K≈0.1406b4 (Timoshenko and Goodier tabulate 0.141). The case uses Roark's closed-form fit for rectangles, evaluated for a square:

K=βb4,β=13−0.21(1−112)=0.1408.

The polar moment of the square, J=b4/6≈0.1667b4, would overestimate the stiffness by 18 %. The free end rotates by

θ=TLGK,G=E2(1+ν).

Here G=80.769 GPa, K=1.4083×107 mm4 and θ=8.7912×10−4 rad.

The warping is largest at the corners and changes sign from one quadrant of the section to the next (inset in the figure). The largest shear stress is at the middle of each side, not at the corners, where it is zero.

Finite element model

MaterialLinear elastic, isotropic
SolverThe app's default solver (conjugate gradients with algebraic multigrid, KoFEM's Rust module, build fem-b229cd7ba59c); geometry and mesh by the KoFEM engine (OCCT, Netgen), the WebAssembly build the app runs: engine-3397ae8ea1eb

The beam is the STEP file a user imports, meshed by Netgen with quadratic tetrahedra; the clamp and the torque each sit on one whole CAD face. The torque is a moment load on the end face. The app turns it into one tangential force per node of the face's surface mesh, proportional to the node's distance r from the centroid of those nodes and scaled so the net force is zero and the moment is T. That is not the exact Saint-Venant stress distribution over a square, but by Saint-Venant's principle the difference only affects the region near the loaded end.

The Results panel reads the twist as the mean in-plane rotation of the end face's nodes about the same centroid, (yuz−zuy)/r2.

Discussion

KoFEM's twist differs from the reference by +0.74 %. Linear tetrahedra would be far too stiff: in the convergence study above their error goes −44.90 % → −26.69 % → −7.77 % as the element size halves. A linear tetrahedron has constant strain, so it follows the shear that varies across a twisted section poorly and locks. The case therefore uses quadratic tetrahedra, which are within a few percent on every mesh (+0.08 % → +1.44 % → +0.74 % → +0.48 %).

From 25 mm down, the quadratic series comes down to the reference from above. Sections inside the bar rotate at the Saint-Venant rate to within a few tenths of a percent; the excess is on the loaded face itself. The torque reaches that face as point forces at its nodes, which deform it locally. The finer the mesh, the smaller each force and its local effect. The coarsest mesh, two elements across the section, lands close to the reference by chance, before this trend sets in.

Two smaller effects remain in a converged result. Saint-Venant's solution assumes that every section warps freely, but the clamp holds the x=0 section flat, which stiffens the bar near it. A square section warps little, so this costs only a few tenths of a percent. And Roark's fit for β is larger than the series value 0.1406, so the reference is 0.17 % low. The ±5 % band covers all three.

Reproduce

In the app: open the model, with its supports, loads and settings.

Or build it yourself, as this page's number was built:

  1. Import beam-torsion.step.
  2. Mesh with a 12.5 mm maximum element size, quadratic elements.
  3. Material Steel: E = 210000 MPa, ν = 0.3.
  4. Support “Clamped end”: Ux, Uy, Uz = 0 on the face through (0, 50, 50).
  5. Load “Torque”: moment Mx = 1000000 N·mm on the face through (1000, 50, 50).
  6. Run the static study. The Results panel compares angle of twist with θ = T·L / (G·K).

From a clone (Bun, bash, curl and Rust), this builds and solves the model with the same engine and prints its line:

git clone https://github.com/mkofler96/KoFEM.git && cd KoFEM
bash scripts/fetch-wasm-engine.sh
cd web && bun install && bun run validate --case beam-torsion
