Plate with a hole, shell elements

The plate with a hole, modelled as a thin-walled part usually is: one layer of shell elements on the mid-surface, with the thickness as a property, instead of solid elements through the thickness. Loaded in its own plane, the shell carries the load as membrane stress, so Kirsch's Kt=3 is the reference here too.

Analytical solution

The derivation is on the solid plate's page. On the edge of the hole the hoop stress is σθθ=σ(1−2cos2θ), largest at θ=±90°, so Kt=3. The solution is a plane-stress solution, which is exactly the state of a flat shell loaded in its plane.

Finite element model

MeshO-grid, 12 rings × 64 around the hole, two triangles per quad: 1,536 3-node Kirchhoff shell triangles (DKT bending, CST membrane)
Unknowns832 nodes, 4,992 degrees of freedom
MaterialLinear elastic, isotropic
SolverKoFEM engine (MFEM), the WebAssembly build the app runs: engine-5ceb743373dd

Each triangle combines a CST membrane, which carries in-plane loads with constant strain, and a DKT plate-bending element. In this load case only the membrane part works. The mesh is the solid plate's O-grid (12 rings × 64 around the hole) with every quad split into two triangles, so the hole edge is a polygon of 64 sides. Shell nodes carry six degrees of freedom, three translations and three rotations. The load is a force on the right edge, which the app spreads as a uniform line load q=σt.

Discussion

KoFEM's Kt differs from 3 by −2.04 %; the solid model of the same plate comes out −7.50 %. Both measure an element value, so both sit a little away from the edge, where the stress has started to fall. A CST triangle has one stress, at its centroid, and the first ring of triangles is split from thin quads, so half of its centroids sit a third of the way across the ring, closer to the edge than the centres of the solid hexahedra. That is one reason the shell gets nearer to 3 on the same grid.

The two models have 4,992 and 4,992 unknowns: the shell's 832 nodes carry six degrees of freedom each, the solid's 1,664 nodes three. Shells pay off when a thin wall bends: one layer of shell elements bends by construction, while solid elements need several layers through the thickness, or quadratic elements, to do the same (see the cantilever).

Reproduce

In the app: open the model, then Studies → Static 1 → Run static solve, select the result plot and set Field to Ux. The Result summary shows Max Ux 9.707e+0 mm.

From a clone (Node.js 20+, bash, curl), this rebuilds the model and its figure:

git clone https://github.com/mkofler96/KoFEM.git && cd KoFEM
bash scripts/fetch-wasm-engine.sh
cd web && bun install && bun run examples:generate-plate-hole-shell
