Plate with a hole (shells)

The same strip as on the solid plate with a hole page, modelled as a thin-walled part usually is: one layer of shell triangles on the mid-surface, with the thickness as a property. Same plate, same load, same reference, Kt=3.14. The two pages show what each element type does with a stress peak.

Analytical solution

The derivation is on the solid plate's page. On the edge of the hole the hoop stress peaks at the points A across the load. In a strip with 2a/W=0.2, Howland's solution puts that peak at Kt=3.14 times the stress σ at the ends. It is a plane-stress solution, which is exactly the state of a flat shell loaded in its own plane.

Finite element model

MeshNetgen, 1 mm maximum element size: 17,283 linear 3-node shell triangles (CST membrane, DKT bending)
Unknowns8,843 nodes, 53,058 degrees of freedom
MaterialLinear elastic, isotropic
SolverThe app's shell solver (conjugate gradients, KoFEM's Rust module, build fem-45b08a9e444e); geometry and mesh by the KoFEM engine (OCCT, Netgen), the WebAssembly build the app runs: engine-3397ae8ea1eb

The strip is symmetric about x=0 and y=0, so the model keeps the quarter x,y≥0. Unlike the solid model it keeps the whole 1 mm thickness: a shell is its mid-surface, so there is no mid-plane to cut at. The edge x=L is pulled with σbt, spread as a uniform line load q=σt.

The app builds the shell from a solid mesh: Netgen fills the 1 mm wall with tetrahedra, and the app replaces the wall by its mid-surface. The faces through the wall, the cut edges and the hole, become the edges of the shell, so each support and the load is picked as an Edge. Netgen puts at least two elements along every edge, so next to the 1 mm cut edge the triangle at A stays about 0.6 mm on every mesh: a smaller maximum element size refines the rest of the hole but not the peak.

Each of the 17,283 triangles combines a CST membrane, with one constant strain and stress per triangle, and a DKT plate-bending element; in this load case only the membrane part works. Shell nodes carry six degrees of freedom. The symmetry edges fix the displacement across the cut and the rotations a mirror plane forbids, plus uz, which only stops the plate floating: an in-plane load never moves it out of its plane.

Mesh convergence: Plate with a hole, shell triangles

Kt scatters a few percent either side of Howland's 3.14 instead of converging: next to the 1 mm cut edge the triangle at the peak stays about 0.6 mm on every mesh, and the read-out is the constant stress of the one or two triangles that meet there. On the finest meshes the peak node is shared by more triangles and reads low.

Discussion

KoFEM's Kt is +1.17 % from 3.14, read as the Results panel reads it: the largest nodal von Mises stress. The solid page, with quadratic tetrahedra, comes out −0.42 %.

The difference is in the elements. A quadratic tetrahedron's stress varies inside it, so it follows the steep drop away from the hole, and the solid model reads the peak slightly low on every mesh. A linear triangle has one stress. At A only one or two triangles meet, so the nodal value is their stress, and it lands above or below 3.14 depending on how the mesher cuts that corner; on the finest meshes the peak moves to the next node along the hole. Over the mesh study above it ranges from 5.6 % below to 7.1 % above, without settling, which is why the band is ±8 %.

For a peak stress in a flat part loaded in its plane, use solid quadratic elements, or check that the shell peak stops changing on finer meshes. Shells pay off when a thin wall bends: one layer of shell elements bends by construction, while solid elements need several layers or quadratic elements to do the same (see the cantilever).

Reproduce

In the app: open the model, with its supports, loads and settings.

Or build it yourself, as this page's number was built:

  1. Import plate-with-hole-shell.step.
  2. Set the body to Shell. Meshing measures the 1 mm wall and replaces it by its mid-surface; the faces through the wall become the shell's edges, which you pick as Edges.
  3. Mesh with a 1 mm maximum element size, linear elements.
  4. Material Steel: E = 210000 MPa, ν = 0.3.
  5. Support “Symmetry x = 0”: Ux, Uz, Ry, Rz = 0 on the edge through (0, 30, 0.5).
  6. Support “Symmetry y = 0”: Uy, Uz, Rx, Rz = 0 on the edge through (80, 0, 0.5).
  7. Load “Tension”: force (5000, 0, 0) N on the edge through (150, 25, 0.5).
  8. Run the static study. The Results panel compares stress-concentration factor with Howland's Kt for 2a/W = 0.2.
