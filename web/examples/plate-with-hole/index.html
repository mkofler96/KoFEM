Plate with a hole

A small circular hole in a plate under tension raises the stress at its edge to three times the nominal value. Kirsch's solution (1898) for this stress concentration is the classic test of how well a solver resolves a stress peak, a harder target than a displacement, which is what the finite element method approximates most accurately.

Analytical solution

Take an infinite plate under uniaxial tension σ along x, with a hole of radius a. In polar coordinates (r,θ) about the hole centre, with θ measured from the load direction, Kirsch's solution of the plane elasticity problem gives the hoop stress

σθθ=σ2(1+a2r2)−σ2(1+3a4r4)cos2θ.

On the edge of the hole, r=a, the radial and shear stresses vanish because the surface is free, and

σθθ(a,θ)=σ(1−2cos2θ).

This is largest at θ=±90°, the points A across the load direction, and the stress concentration factor is

Kt=σmaxσ=3.

At θ=0 the edge is in compression, σθθ=−σ, although the plate is pulled. Along the transverse axis the stress decays quickly with the distance from the hole,

σxx(0,y)=σ(1+a22y2+3a42y4),

to 1.22σ at y=2a and 1.04σ at y=4a (figure, right). At the edge it falls steeply, dσxx/dy=−7σ/a. The solution does not depend on Poisson's ratio, so it holds in plane stress and plane strain alike.

A real plate has edges. In a long strip of width W=2b the load that the hole cannot carry has less room to flow around it, so the peak rises. Howland (1930) solved the strip. On the gross stress σ at the ends his factor grows with 2a/W: 3.00 at 0.0, 3.03 at 0.1, 3.14 at 0.2, 3.36 at 0.3, 3.74 at 0.4, 4.32 at 0.5.

This strip has 2a/W=0.2, so its reference is Kt=3.14. Heywood's and Peterson's fits to later solutions give the same value. The strip has to be long for this: its ends must be far enough from the hole that the uniform end tension has become the strip's own stress field. Built as a square plate of the same width, this model reads about 3.3.

Finite element model

MeshNetgen, 2 mm maximum element size: 13,522 quadratic 10-node tetrahedra (P2)
Unknowns27,705 nodes, 83,115 degrees of freedom
MaterialLinear elastic, isotropic
SolverThe app's default solver (conjugate gradients with algebraic multigrid, KoFEM's Rust module, build fem-45b08a9e444e); geometry and mesh by the KoFEM engine (OCCT, Netgen), the WebAssembly build the app runs: engine-3397ae8ea1eb

The strip is symmetric about x=0, about y=0 and about its mid-plane, and so is the load. The model keeps one eighth: the quarter x,y≥0, upper half of the thickness. Each cut face gets a symmetry support that fixes only the displacement across it: ux on x=0, uy on y=0 and uz on the mid-plane. Together they stop every rigid-body motion and restrain nothing else, so the plate contracts freely, as in Kirsch's problem. A fixed end would not. The strip reaches L=3b on each side of the hole, and its thickness t=a/10 keeps it in plane stress.

Netgen meshes it with quadratic tetrahedra and a 2 mm maximum element size. The app has no element size per face, but Netgen puts at least two elements along every edge. The edge through the thickness at A is only 0.5 mm long, so the elements there are a few tenths of a millimetre, much finer than in the rest of the plate, where the stress hardly changes.

The read-out is the one the Results panel shows. The solver gives one von Mises stress per element, at its centre, and the app averages these to the nodes. The hand check takes the largest nodal value on the hole face and divides it by σ. At A the surface is free and the only stress is σθθ, so there the von Mises stress equals σθθ.

Discussion

KoFEM's Kt differs from Howland's 3.14 by −0.42 %. The nodal average explains why it reads low. The elements around A have their centres a fraction of an element inside the plate, where the stress has already started to fall, and with the steep drop 7σ/a even a small distance counts. Finer elements at A would move the centres closer to the edge.

The mesh convergence study above changes only the maximum element size. With quadratic elements the result stays between 0.4 % and 1.6 % below 3.14 on every mesh, because the elements at A keep their size. That is why the band is ±3 %. Linear elements read several percent high on the same meshes: their constant stress per element is noisy where the stress changes fast. For a peak stress in a design, use quadratic elements and refine at the stress raiser until the peak stops changing. The shell page models the same strip with linear shell triangles.

Reproduce

In the app: open the model, then Studies → Static 1 → Run static solve, select the result plot and set Field to Ux. The Result summary shows Max Ux 7.380e-2 mm.

Or build it yourself, as this page's number was built:

  1. Import plate-with-hole.step.
  2. Mesh with a 2 mm maximum element size, quadratic elements.
  3. Material Steel: E = 210000 MPa, ν = 0.3.
  4. Support “Symmetry x = 0”: Ux = 0 on the face through (0, 30, 0.25).
  5. Support “Symmetry y = 0”: Uy = 0 on the face through (80, 0, 0.25).
  6. Support “Mid-plane”: Uz = 0 on the face through (75, 25, 0).
  7. Load “Tension”: force (2500, 0, 0) N on the face through (150, 25, 0.25).
  8. Run the static study. The Results panel compares stress concentration σmax/σ with Howland's Kt for 2a/W = 0.2.

From a clone (Bun, bash, curl and Rust), this builds and solves the model with the same engine and prints its line:

git clone https://github.com/mkofler96/KoFEM.git && cd KoFEM
bash scripts/fetch-wasm-engine.sh
cd web && bun install && bun run validate --case plate-with-hole
