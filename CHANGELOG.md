# Changelog

User-visible changes to KoFEM, newest first. Each section is written once, by the
release PR that introduces the version. Feature PRs do not edit this file. See
[Releases in AGENTS.md](AGENTS.md#releases).

Changes to numerical results, solver defaults or saved-model compatibility are
always listed, under **Changed** or **Breaking**, with what moved and why.

## [0.1.0] - 2026-10-08

The first tagged release. kofem.org has been deployed continuously from `main`
before this, and still is. This version marks a reference point rather than a
change in behaviour.

### What KoFEM does at 0.1.0

- Imports STEP and IGES geometry and runs the whole pipeline in the browser:
  Netgen volume meshing, then a linear-elastic MFEM solve. Nothing is uploaded.
- Meshes thin-walled bodies as shells (Kirchhoff/DKT) and detects them
  automatically, so one model can mix shells and solids.
- Supports multibody assemblies with per-body materials, bonded ties and RBE3
  shell-to-solid coupling.
- Boundary conditions: fixed and per-DOF constraints and prescribed
  displacements, on solids and shells. Loads: forces, moments and multiple load
  cases on faces and edges, plus reference points.
- Sizes the mesh to the geometry by default.
- Topology optimization:
  - SIMP minimum compliance, minimum volume under a compliance limit, and
    stress-constrained variants, plus a reaction–diffusion level-set optimizer.
  - Works on shell and coupled shell/solid models.
  - Streams the density field live during the run, and exports the result as STL.
- Pre-solved examples at [kofem.org/examples](https://kofem.org/examples/), each
  of which opens directly in the app.

### Known limitations

- Linear statics only: no geometric or material nonlinearity, no dynamics.
  Bodies are bonded; there is no separating or frictional contact.
- KoFEM is research-grade software. Verify results independently before relying
  on them; see [DISCLAIMER.md](DISCLAIMER.md).
